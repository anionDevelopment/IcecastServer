This table lists the user-facing features of `IcecastServer`, a docker-image for running an Icecast-server in a container. The state reflects whether the feature is actually available according to the documentation (`available`) or planned but not yet implemented (`unavailable`).

| ------ | --------- | ------------------------------------------------------------------------ |
| feat-1 | available | Run an Icecast media-streaming-server inside a docker-container.         |
| feat-2 | available | Configure the Icecast-server for use in a containerized deployment.      |
